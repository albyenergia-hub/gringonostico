# Gringonostico

Previsioni di tennis (singolare ATP, WTA, Challenger): probabilità per superficie, scontri diretti, forma, servizio e stile di gioco.

- `index.html`: la pagina (si aggiorna da sola con `nuovi_risultati.json`)
- `dati_app.json`: dati storici e rating
- `nuovi_risultati.json`: risultati recenti, aggiornati ogni 3 ore da GitHub Actions
- `aggiorna_risultati.py`: scarica i risultati dal tabellone pubblico di ESPN

Dati storici: Jeff Sackmann (Tennis Abstract), CC BY-NC-SA 4.0, e Match Charting Project. Risultati recenti: ESPN. Foto: Wikipedia/Wikimedia Commons. Solo uso personale e non commerciale. Non conosce gli infortuni.
